# Research log

Chronological record of decisions. Enough detail that the methodology chapter
can be written from this file.

## Template

```
### YYYY-MM-DD
- Ran: <command>
- Parser state: <commit hash of src/ordinance_eda_pipeline.py>
- Coverage: enactment n%, ord-no n%, series n%, approval n%
- Flags: n misfiled, n out of scope, n review, n unresolved
- Decisions: <what you changed and why>
- Open questions: <what to check next>
```

## Entries

### YYYY-MM-DD
- Project set up, self-test passing.
- Corpus not yet in place.
